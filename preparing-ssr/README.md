# Server Side Rendering (SSR)_ как добавить в Vue 3 + Vite приложение

All functionality is implemented using HTML5, pure CSS & JavaScript.

**How to use:**

Just clone or download this repository. Start local server [serve](https://github.com/vercel/serve) npm package. That's all...
Or you can read the material right here by clicking on the link in the upper right corner [preparing-ssr](https://alekstar79.github.io/preparing-ssr).

Clone this repo:
```shell
git clone git@github.com:alekstar79/preparing-ssr.git
```
Go to project directory:
```shell
cd preparing-ssr
````
Install package serve (by Vercel) globally
````shell
npm install --global serve
````
Once that's done, you can run this command inside your project's directory...
```shell
serve
```
...or
```shell
serve -s .
```
...or specify which folder you want to serve:
````shell
serve folder-name/
````
