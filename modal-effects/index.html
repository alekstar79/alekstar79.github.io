How to connect an effect

How it works

The effect is pure CSS. JS is only needed to toggle the open class on the overlay. Add it — the browser plays the opening animation. Remove it — the browser plays the closing.

How to connect

  1. Open the card of the desired effect.
  2. Click Copy in the top-right corner of the code block.
  3. Paste the copied CSS into your stylesheet.
  4. In HTML, wrap the modal in .overlay with the effect class, and put .modal with content inside.
  5. In JS, toggle the open class on the wrapper.

Markup

The outer block is .overlay plus the chosen effect class, e.g. overlay-spring. Inside — .modal with any content. Open and close buttons are ordinary <button> with ids.

Open and close

All interaction is a single open class on the overlay:

  • Open — overlay.classList.add('open').
  • Close — overlay.classList.remove('open').
  • Backdrop click — a listener on overlay checks event.target === overlay and removes the class.
  • Escape — a listener on document checks event.key === 'Escape' and removes the class.

What is in the card code

The card CSS is self-contained: it includes both the base overlay styles (positioning, centering, show/hide) and the effect itself. Copy — paste — it works. Nothing else to look for.

Good to know

  • The effect also works on non-modal blocks: the .overlay-* rules are enough.
  • The open class can be toggled not only on click — on hover, on scroll, on IntersectionObserver.
  • Multiple modals with different effects coexist on one page: .overlay-* classes do not conflict.
  • With prefers-reduced-motion: reduce animations are disabled automatically.
